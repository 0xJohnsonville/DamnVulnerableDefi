# Damn Vulnerable DeFi

Working through Damn Vulnerable DeFi, a well-known set of smart contract security challenges where each level involves finding and exploiting a vulnerability in a DeFi protocol.

## Tech stack
- Solidity
- Foundry (the framework the official challenge set is built on)

## What this demonstrates
Applied smart contract security skills: reading unfamiliar Solidity code, identifying exploitable logic (reentrancy, price manipulation, access control gaps, and similar), and writing exploit contracts and tests to prove each vulnerability.
